## 一、開始前（約 2 分鐘）

1. **加入公司的 LINE 官方帳號為好友**（管理員會另外給連結）。沒加好友就收不到簽核通知。
2. **在 LINE 裡點這個連結登入**：
   https://liff.line.me/2012594772-22NJxRHt
3. 第一次登入會看到「**登入成功：你的名字（待啟用）**」，這是正常的。
   系統會自動用 LINE 通知管理員；也可以順便在群組說一聲「我登入了」。
4. 開通後**重新點一次連結**，就會看到「新增申請」「我的申請」等分頁。

> 主管與文管開通後會多出「待我簽核」或「文管發放」分頁，右上角也會有「管理看板」。

## 二、測試項目

做完一項就在方框內打勾，有問題請照第三段回報。
**表單內容請填假資料**（例如品號 `TEST-001/測試零件`），不要填真的客戶名稱。

### 所有人（申請人）

- [ ] **送出申請**：在「新增申請」填寫全部必填欄位 → 按「送出申請」→ 畫面顯示單號（例如 `DOC-20261127-001`）
- [ ] **必填檢查**：什麼都不填直接按「送出申請」→ 每個沒填的欄位下方都有紅字提醒
- [ ] **品號格式**：品號那格輸入 `ABC123`（沒有斜線）→ 會提醒格式要「品號/名稱」
- [ ] **外部用途**：申請用途選「提供給客戶」→ 出現黃色的外部用途提醒
- [ ] **草稿自動暫存**：填到一半直接關掉 LINE 頁面 → 重新打開，內容還在，上方顯示「已還原上次還沒送出的內容」；按「清除重填」可清空
- [ ] **記住部門**：送出一張後再填下一張，「所屬部門」已自動選好
- [ ] **查看進度**：到「我的申請」→ 點開單據 → 看得到進度圓點與簽核紀錄
- [ ] **撤回**：送出一張後，主管還沒簽前，在「我的申請」按「撤回申請」
- [ ] **被駁回後重新申請**：被駁回的單據點開 → 按「複製內容重新申請」→ 內容自動帶回表單
- [ ] **收到通知**：被駁回、已發放時，LINE 都有收到訊息；點訊息會直接跳到那一張單並自動展開

### 部門主管（第一關）

- [ ] 部屬送出申請後，LINE 收到「待簽核」通知；點連結會直接跳到那一張單（短暫加上藍框）
- [ ] 「待我簽核」分頁上的數字正確
- [ ] **核准**：按「核准」→ 確認 → 單據從清單消失
- [ ] **駁回**：按「駁回」→ 沒填原因直接按「確認駁回」會被擋下 → 填原因後送出

### 核發主管（第二關）

- [ ] 第一關核准後，LINE 收到通知，並在「待我簽核」看到單據，畫面寫「第二關・核發主管」
- [ ] 核准一張、駁回一張
- [ ] **管理看板（請用電腦）**：打開 https://ming32409-boop.github.io/drawing-request/dashboard.html
  - [ ] 切換「本月／3 個月／12 個月／今年／全部」，數字與圖表會跟著變
  - [ ] 選「自訂」→ 選日期 → 按「套用」
  - [ ] 按「匯出 Excel」→ 用 Excel 打開，中文正常、沒有亂碼

### 文管

- [ ] 第二關核准後，LINE 收到通知，並在「文管發放」看到單據
- [ ] 不選發放方式直接按「確認已發放」→ 會被擋下
- [ ] 選「其他」但不寫說明 → 會被擋下
- [ ] 選「雲端連結」但不貼連結 → 會被擋下；貼上連結後發放 → 申請人的 LINE 通知與「我的申請」裡都看得到、點得開這個連結
- [ ] 正常發放一張 → 申請人收到「已發放」通知
- [ ] 管理看板同上（請用電腦）

### 系統管理員

- [ ] 有新同仁第一次登入時，LINE 收到「新帳號待啟用」通知，點連結直接打開「管理設定」
- [ ] 在「管理設定」→「帳號與角色」按「啟用」→ 對方收到「帳號已開通」通知
- [ ] 點開某位同仁，用開關設定「核發主管」「文管」「系統管理員」，畫面立刻顯示已儲存
- [ ] 試著把自己（唯一的管理員）的「系統管理員」關掉 → 會被擋下，開關自動恢復
- [ ] 「部門與主管」：為每個部門選好部門主管；沒選的部門會顯示「未設定主管」
- [ ] 試著停用某位部門主管的帳號 → 會被擋下，提示先更換部門主管
- [ ] 新增一個測試部門 → 申請表的部門選單出現它；停用後就不再出現

### 畫面與手機

- [ ] 用自己的手機在 **LINE 裡**打開，字和按鈕大小合適，不用左右滑動
- [ ] 「需要日期」欄位點得開、選得了日期
- [ ] 手機設定成深色模式時，畫面也看得清楚

## 四、常見問題

**Q：一直顯示「待啟用」？**
系統已通知管理員，但管理員還沒開通。開通後你會收到「帳號已開通」的 LINE 通知，再重新點一次連結即可；超過一個工作天請直接聯絡管理員。

**Q：打開新增申請，出現上次沒填完的內容？**
這是自動暫存的草稿，只存在你自己的手機。不需要的話按「清除重填」。

**Q：沒收到 LINE 通知？**
先確認已把官方帳號加為好友、沒有封鎖。通知偶爾會晚 1 分鐘左右；還是沒收到就回報單號。

**Q：用電腦瀏覽器打開，被轉到 LINE 登入頁？**
這是正常的，用 LINE 帳號登入即可。

**Q：看不到「管理看板」？**
看板只開放給核發主管、文管與系統管理員。

**Q：在 LINE 裡按「匯出 Excel」沒反應？**
LINE 內建瀏覽器有時不能下載檔案，請改用電腦瀏覽器打開管理看板。

**Q：畫面還是舊的樣子？**
關掉 LINE 裡的頁面重新打開；還不行的話，把 LINE 完全關掉再開。
